# TCG Toolkit

在游游亭（yuyu-tei.jp）找卡、比价、管理收藏和购物车的工具。
支持 WSR、WS、PM、Lycee、ChaosTCG、Shadowverse Evolve 六个游戏，可以一次同时搜索多个游戏。

在线版本：<https://oscarzhang-735.github.io/TCG-Toolkit/>（验证邮箱并注册账户后即可使用）

## 功能

- **搜索**：输入卡名或编号，一次查遍多个游戏，看到价格和库存。
- **筛选和排序**：按稀有度、库存、价格范围、游戏筛选，按价格、名称、编号或库存排序；列表和网格两种视图可切换。
- **收藏夹**：点卡牌上的 ☆ 收藏，之后随时一键刷新最新价格和库存。
- **卡牌库**：记录自己手上有哪些卡、各有几张，并按游戏、稀有度统计。
- **游游亭购物车**：在本站直接加购、修改数量、移出购物车，最后到游游亭结算。
- **多语言和货币**：界面可选简体中文或 English；提供汇率转换。

## 快速上手

1. **注册登录**：首次使用点“没有账户？注册”。用户名 3–32 位字母、数字、下划线或连字符，密码 8–18 个字符。填写邮箱并发送验证码，在 10 分钟内输入邮件中的六位验证码，提交后自动登录。之后可使用用户名或已验证邮箱登录。老账户仍可用用户名登录，在用户中心验证并补绑邮箱。
2. **搜索**：在搜索框输入卡名或编号，勾选要查的游戏，点“搜索”。结果多时会自动继续加载，可以随时点“停止”。
   点击搜索框可以看到最近的搜索记录。
3. **复制编号**：点击任意卡牌编号即可复制。
4. **收藏**：点 ☆ 收藏卡牌，在左侧“收藏夹”中查看；可以单张刷新，也可以“刷新全部”。
5. **卡牌库**：在左侧“卡牌库”点“添加卡牌”，填写游戏、编号、稀有度、名称和数量即可。
6. **切换语言和货币**：在左侧边栏底部选择。

## 使用游游亭购物车

想在本站加购，需要先把你在游游亭的登录凭据告诉本站：

1. 打开左下角头像进入“用户中心”，找到“游游亭登录凭据”。
2. 按面板里“如何获取”的图文步骤，从浏览器复制 **Cookie（laravel_session）** 和 **CSRF Token**，
   填入后点“保存并验证”。看到绿色的“已配置凭据”就说明成功了。
   也可以改用面板里的“从 cURL 导入”，粘贴一段复制好的请求即可。
3. 回到搜索结果，用每张卡旁边的 `+` / `−` 加购或减少，也可以直接点数字输入想要的数量。
4. 左侧“购物车”页面可以查看全部已加购的卡、获取最新库存、修改数量或移出购物车。
5. 准备好后点“前往游游亭结算”，在游游亭官网完成付款。

小提示：

- 凭据只保存在当前浏览器标签页里，**关闭标签页或退出登录后需要重新填写**；本站服务器不会保存它。
- 如果提示“游游亭拒绝了凭据”，通常是游游亭那边登录过期了，重新复制一次两项即可。
- 输入的数量超过库存或其他限制时，会自动调整到允许的数量并给出提示。
- 结算和付款都在游游亭完成，本站不会替你下单。

## 本地运行

可以在自己的电脑上用 Docker 运行：

1. 安装并打开 [Docker Desktop](https://www.docker.com/products/docker-desktop/)。
2. 下载本项目，在项目文件夹里把 `.env.example` 复制一份并改名为 `.env`。
3. 用记事本打开 `.env`，确认 `TCG_TRUSTED_ORIGINS=http://localhost:8000`（这是你打开网页时用的地址），并按 [邮箱配置说明](docs/developer.md#邮箱注册与验证) 填写 SMTP 和验证码密钥。未配置邮件服务时，老账户可以登录，新账户无法注册。
4. 在项目文件夹里打开终端，运行：

   ```powershell
   docker compose up -d --build
   ```

5. 用浏览器打开 <http://localhost:8000>。

运行 `docker compose stop` 来停止，再次启动运行 `docker compose start`。
你的账户、收藏和卡牌库会一直保留，重新启动或更新都不会丢失。
